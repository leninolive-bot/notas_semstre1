1. Formulación del problema: El problema de que se trate se define en forma amplia y sin detalles.
2. Análisis del problema: En esta etapa se define el problema con todo detalle (requiere investigación exhaustiva)
3. Búsqueda de soluciones: Las soluciones alternativas se reúnen mediante la indagación, invención, investigación, etc.
4. Decisión: Todas las alternativas se evalúan, comparan y seleccionan hasta que se obtiene la solución optima (de acuerdo a la necesidad primaria)
5. Especificación: Exponer por escrito sin omitir detalles.
